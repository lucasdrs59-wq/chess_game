# Sécurité

## Versions prises en charge

Seule la branche `main` est maintenue.

## Signaler une vulnérabilité

Ne pas ouvrir d’issue publique pour une vulnérabilité. Utiliser le formulaire
privé [GitHub Security Advisory](https://github.com/lucasdrs59-wq/chess_game/security/advisories/new).

Préciser la zone concernée, les étapes de reproduction et l’impact probable,
sans joindre de compte joueur, partie privée, jeton ou donnée personnelle.

## Modèle de menace

- aucune authentification et aucun secret applicatif ;
- stockage local contrôlé par le navigateur ;
- données distantes limitées à l’API publique Chess.com ;
- aucun moteur, overlay, lecteur d’écran tiers ou mécanisme d’analyse live.
